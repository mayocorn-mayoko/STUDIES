# STUDIES

STUDIESは、自分の勉強を「見える化」して管理するためのアプリです。
今日の目標を決め、タイマーで勉強時間を計測し、その記録を履歴として積み上げていくことができます。

## 始め方

アプリを起動すると、ブラウザで STUDIES の画面が開きます。
最初に表示されるのが「ホーム画面」です。ここから他の画面にも移動できます。

## 各ページの説明と使い方

### ホーム画面

アプリを開いたときに最初に表示される画面です。次の内容が一覧できます。

- **今日の目標**: 目標設定画面で登録した、今日の目標
- **今日の勉強予定**: やることリスト。クリックすると完了/未完了を切り替えられる
- **近い試験・締切**: カレンダーに登録した試験・締切までの日数(「あと◯日」)。登録がなければ表示されない
- **勉強履歴**: これまでに記録した勉強の一覧。タイマーで記録したものには「タイマー」、手動で追加したものには「手動」、他の人のファイルから取り込んだものには「インポート」のラベルが付き、ひと目で区別できる

画面上部のメニューから、カレンダー・目標設定・タイマー・使い方の各画面にいつでも移動できます。「STUDIES」のロゴをクリックすると、どの画面からでもホーム画面に戻れます。

### カレンダー

月ごとのカレンダーで予定や勉強の様子を確認する画面です。

- 日付をクリックすると、その日の予定・目標・勉強履歴が下に表示される
- 予定の内容と種類(勉強予定／試験・締切／休み・予備)を選んで追加できる。開始・終了時刻は任意。削除もできる
- 予定は種類ごとに色が変わる(青: 勉強予定、赤: 試験・締切、グレー: 休み・予備)
- 勉強時間が長い日ほど、日付マスの緑色が濃くなる
- 選んだ日の「勉強予定の完了数」と「実際の勉強時間」が並んで表示される

### 目標設定画面

日付ごとに目標とやることリストを管理する画面です。

- 上部で日付を選ぶと、その日の目標・予定を確認・編集できます(最初は今日の日付になっています)
- 「開始」と「終了」の欄に、たとえば問題集のページ範囲などを入力して目標を追加できます。「終了」は空欄のままでも登録できます
- 1日に複数の目標を追加でき、一覧の「削除」ボタンから個別に削除できます
- やることリストは、テキストを入力して「追加」を押すと登録されます。完了チェックや削除もこの画面から行えます
- 画面の下には、すべての記録を消去するボタンもあります(確認してから実行されるので安心です)

### タイマー画面

勉強時間を計測する画面です。

- 「カウントアップ(経過時間を計る)」と「カウントダウン(設定した時間から減っていく)」を切り替えられます
- 「開始」を押すと計測が始まります。稼働中は開始ボタンが暗く表示され、操作できない状態であることがひと目でわかります
- 「一時停止」で計測を止めて、続きから再開できます
- 「全画面表示」ボタンで、タイマーだけを大きく表示できます
- 「停止」を押すと、その回の勉強を記録として残すかどうかを確認する画面が出ます。科目名やメモを入力して残すこともできます

### 記録を手動で追加

タイマーを使わずに、あとから勉強内容を記録したいときに使う画面です。ホーム画面の履歴一覧にあるリンクから移動できます。日付・科目名・学習時間・メモを入力して追加すると、ホーム画面の履歴に反映されます。

### 書き出し

ホーム画面の「書き出し」から、記録をファイルとして保存できます。他の端末に移したり、バックアップを取っておいたりするのに使えます。

- 日付の範囲を指定して、その期間の記録だけを書き出せます
- 「目標」「勉強予定」「勉強履歴」のうち、書き出したいものだけを選べます

### 読み込み

ホーム画面の「読み込み」から、書き出しておいたファイルを選ぶと、その内容が取り込まれます。今あるデータを上書きすることはなく、追加される形になります。取り込んだ内容には「インポート」というラベルが付き、自分で入力したものと区別できます。

### 他の人のデータを見る

友人などから共有されたファイルを、自分の記録と混ぜずに見たいときに使う画面です。ここで開いた内容は表示されるだけで、自分の記録には一切保存されません。

### 使い方

STUDIESの使い方をまとめた説明ページです。メニューの「使い方」からいつでも開けます。

## データの保存について

STUDIESの記録は、いま使っているブラウザの中にだけ保存されます。そのため、次の点にご注意ください。

- 別のパソコンやスマートフォン、別のブラウザからは同じ記録を見ることはできません。他の端末と記録を共有したいときは、「書き出し」と「読み込み」を使ってください
- ブラウザの閲覧データを削除すると、STUDIESの記録も一緒に消えてしまいます。大事な記録は、ときどき「書き出し」でファイルに保存しておくと安心です
